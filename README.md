# 🎓 Gestión de Prácticas Profesionales - CEMU Uneatlantico

Este proyecto es una aplicación web desarrollada para el **CEMU de la Universidad Europea del Atlántico**, que permite a los estudiantes **visualizar las prácticas profesionales disponibles** y **realizar solicitudes** a las mismas.  

## 🚀 Funcionalidades principales

### 💼 Prácticas Profesionales
- Visualización de todas las prácticas registradas.  
- Detalle de cada práctica con información como:  
  - Título de la práctica  
  - Ubicación  
  - Modalidad (presencial, remoto, híbrido)  
  - Tipo de práctica  
  - Jornada  
  - Estudios mínimos requeridos  
  - Idiomas solicitados  
  - Fecha de inicio y periodo de duración  
  - Experiencia mínima  
  - Conocimientos previos  
  - Descripción detallada  
  - Empresa que ofrece la práctica  
  - Grado al que está asociada  
- Posibilidad de **solicitar prácticas** (postulación por parte del alumno).  
- Filtros y búsqueda para localizar prácticas por grado, empresa o características.  

## 🛠️ Tecnologías utilizadas

- **Frontend:** React + Next.js + TypeScript  
- **Estilos:** TailwindCSS + Material UI (MUI)
